# ReVPN

ReVPN is an Android VPN client for a personal Xray server.

## What the stack does

- Android `VpnService` creates the system TUN interface and captures device traffic.
- VLESS carries that traffic between the phone and the Xray server.
- XTLS Vision is the optimized VLESS flow used with TCP/RAW.
- REALITY provides the TLS-looking transport layer and configurable SNI/fingerprint profile.
- HAProxy on the VPS can route several REALITY profiles through the same public TCP/443 port.

VLESS is therefore not the camouflage itself. It is the lightweight proxy protocol inside the connection. REALITY is the part responsible for the TLS appearance.

## Current app features

- dark mobile UI inspired by the supplied references
- one-tap connect/disconnect
- multiple server profiles
- selectable REALITY profiles
- built-in profile labels for MAX, VK, VK Video and Yandex Disk
- standard Android foreground notifications for Connecting / Connected / Disconnected
- notification Connect / Disconnect actions
- import of the server JSON generated by the VPS installer
- Android 5.0+ (`minSdk 21`)
- official `XTLS/libXray` Android AAR, downloaded at build time
- GitHub Actions APK build

## Important limitation of whitelist mode

Changing SNI or the TLS fingerprint does **not** change the destination IP of the connection. If a mobile network allows only the actual IP ranges of selected services, a random VPS IP can still be blocked before REALITY starts.

The selectable MAX/VK/VK Video/Yandex Disk entries in ReVPN are REALITY/SNI profiles. They are useful only on networks where the route to the VPS itself is reachable and the filtering happens at a layer where this TLS appearance matters.

## Build APK

GitHub Actions automatically builds a debug APK after Android source changes.

Open:

`Actions -> Build Android APK -> latest successful run -> Artifacts -> ReVPN-debug`

For a local build:

```bash
bash scripts/fetch-libxray.sh
gradle :app:assembleDebug
```

## Ubuntu 24.04 server

On the VPS:

```bash
sudo apt update
sudo apt install -y git
git clone https://github.com/ReVerfyx/ReVPN.git
cd ReVPN
sudo bash server/install.sh
```

The installer writes the Android client configuration to:

```
/root/revpn-client.json
```

Copy that JSON, open ReVPN, then:

`Настройки -> Импорт конфигурации -> вставить JSON -> Импортировать`

For extra servers, run the installer on each VPS and combine the server objects into one `servers` array before importing.
